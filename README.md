# FP DAW

## Descripción
Este repositorio contiene los ejercicios prácticos de **Formación Profesional en Desarrollo de Aplicaciones Web (DAW)** de la academia **Digitech**.  
El objetivo del proyecto es aplicar los conocimientos adquiridos durante el curso para desarrollar una aplicación funcional utilizando buenas prácticas de programación, estructura de proyecto y control de versiones con Git.
